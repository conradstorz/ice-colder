{# Shared "Copy" button (todo section 5). Parameters: copy_target CSS selector of the element whose visible text is copied (a one-value chip or a whole list; list items copy one per line) copy_label optional button label, default "Copy" The click handler is inline on purpose: it survives htmx swaps with no script re-execution, and this codebase ships no JS framework. The Clipboard API exists only in a secure context, and the edge dashboard is plain-HTTP on the LAN, so navigator.clipboard is undefined there. The handler therefore always selects the target text first and wraps the clipboard call in try/catch: when the copy is unavailable or refused the label reads "Selected" and the text stays highlighted for the OS copy gesture. Tap feedback: the label swaps to "Copied"/"Selected" for two seconds. #} {% set _label = copy_label | default("Copy") %}
