# Test Suite Hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the three largest sources of technical debt in `tests/`: unpoliced private-attribute access outside the VMC, route-module globals leaking between tests, and wall-clock sleeps where a deterministic signal exists.

**Architecture:** Three independent tracks, each landing as its own small PR-sized group of commits. Track A generalises the existing `tests/test_no_private_access.py` guard into a per-file ratchet, then promotes the handful of private names tests genuinely need into public seams so budgets can fall. Track B adds one autouse fixture that snapshots and restores every `web_interface.context` global, backed by a guard test that fails when a new global is added without being listed. Track C replaces timing-based waits with the existing `FakeTaskRunner` fire-by-label API, a `settle()` yield helper, and real completion signals.

**Tech Stack:** Python 3.12, pytest, pytest-asyncio (already configured), `uv run pytest`, `ruff`.

## Global Constraints

- No production behaviour change. Production edits are limited to renaming a private name to a public one, adding a read-only property, or adding `queue.task_done()`. Every rename keeps the old private name out (no alias), so the guard counts fall for real.
- The full suite stays green after every task: `uv run pytest` and `ruff check .` then `ruff format .`.
- Plan style per project convention: each task specifies interfaces and tests; implementers write the bodies.
- Commit after every task. Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Do not chain shell commands with `&&`.

### Task 1: Generalise the guard into a per-file ratchet

**Files:**
- Modify: `tests/test_no_private_access.py`
- Create: `tests/private_access_budget.py` (data only: one dict)

**Interfaces:**
- Produces, in `tests/test_no_private_access.py`:
  ```python
  PRIVATE_ATTR_RE = re.compile(r"\b(?!self\b|cls\b)[A-Za-z_][A-Za-z0-9_]*\._[a-z][A-Za-z0-9_]*")
  PRIVATE_IMPORT_RE = re.compile(r"^\s*from\s+\S+\s+import\s+(.+)$")   # names split on ',', part before ' as ', flagged if it starts with '_'
  def count_private_access(path: Path) -> list[str]   # "rel:line: text" per unmarked hit (attr + import)
  def current_budget() -> dict[str, int]              # {rel_posix_path: unmarked hit count}, zero-count files omitted
  if __name__ == "__main__": print(current_budget())  # paste-ready for the budget file
  ```
- Produces, in `tests/private_access_budget.py`:
  ```python
  BUDGET: dict[str, int] = { "tests/test_simulator_base.py": 150, ... }   # generated by Task 1 step 4
  ```
- Rules the test enforces:
  1. A file not in `BUDGET` has budget 0. `vmc._`/`machine._` therefore stay at zero with no special case.
  2. A file whose count **exceeds** its budget fails, listing each `rel:line: text`.
  3. A file whose count is **below** its budget fails with "lower BUDGET[...] to N". Budgets only move down.
  4. A `# private: <reason>` marker on one of the three lines above a hit still exempts that line, unchanged.
  5. `self._x`, `cls._x`, and dunder access (`vmc.__class__`) are never hits. Aliased imports (`import logger as _loguru`) are not hits; `from m import _foo` is.

**Tests (add to `tests/test_no_private_access.py`):**
- `test_regex_ignores_self_cls_and_dunder` — sample lines, assert no match.
- `test_regex_matches_object_private_and_private_import` — `sim._fault_state`, `from web_interface.routes.health import _fault_gate` both match; `from loguru import logger as _loguru` does not.
- `test_marker_exempts_line` — three-line lookback still honoured.
- `test_budget_is_exact` — the ratchet test itself: no file over, no file under.

**Steps:**
- [ ] Write the four tests against the new names; run `uv run pytest tests/test_no_private_access.py -v`; expect NameError/ImportError failures.
- [ ] Implement `PRIVATE_ATTR_RE`, `PRIVATE_IMPORT_RE`, `count_private_access`, `current_budget`, keeping `_is_marked` and `_iter_test_files`. Skip `tests/private_access_budget.py` and the guard itself when walking files.
